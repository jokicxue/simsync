## 💡 截图建议与小贴士

1. **尺寸与清晰度**：
   - 建议在 PC 浏览器（Chrome / Edge）中以 100% 缩放截取，窗口宽度推荐 1280px ~ 1440px。
   - 截图中若有个人敏感手机号或隐私短信内容，建议在截屏工具中进行模糊/马赛克打码，或使用测试号码与测试短信。
2. **主题模式**：
   - 可截取浅色（白色）或深色（黑色）皮肤，建议全套截图保持统一的主题色调风格。
3. **启用截图**：
   - 将截图文件保存在当前目录（例如 `docs/images/dashboard.png`）；
   - 在项目根目录的 [`README.md`](../../README.md) 中找到对应被 `<!-- ... -->` 注释掉的 `<img>` 标签，删除注释符号即可在 GitHub 首页优雅展示！
