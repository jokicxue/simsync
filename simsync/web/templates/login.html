🔑 重置管理员密码

支持通过通知邮箱在线接收验证码重置，或直接在 Docker 宿主机终端执行重置命令。

点击下方按钮，系统将向您在通知配置中绑定的管理员邮箱发送 6 位验证码（10 分钟有效）：

若未配置 SMTP 邮件通知或无法收取邮件，请直接在 Docker 宿主机终端（通过 SSH 或终端控制台）中执行以下命令：

方式 A：直接重置密码并关闭 2FA
sudo docker exec -it simsync python -m simsync.security.reset --password admin --disable-2fa
* 执行后管理员密码将重置为 admin，并自动停用 2FA。
方式 B：恢复默认凭据 (admin / admin)
sudo docker exec -it simsync python -m simsync.security.reset --clear
* 执行后恢复默认管理员账号 admin 与密码 admin。
💡 容器终端执行说明：
若宿主机未配置 sudo 或直接在容器管理面板（如 Portainer / Docker 仪表盘 / 容器 Web 终端）内操作，可进入 simsync 容器终端直接执行：
python -m simsync.security.reset --password admin --disable-2fa
